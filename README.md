# Nayic

Mini juegos y landing de [nayic.com.ar](https://nayic.com.ar/).

## Juegos

| Carpeta | Juego |
|---|---|
| `games/viborita` | La Viborita |
| `games/tetris` | Tetris Texturas |
| `games/gato` | Gato |
| `games/memoria` | Juego de memoria |
| `games/tateti` | Tateti |

Cada juego es un proyecto Vite independiente:

```bash
cd games/<juego>
npm i
npm run dev
```
